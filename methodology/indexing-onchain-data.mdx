This page explains where vaults.fyi data comes from: how vault state is read from chain, how share price is derived for each vault type, and how fresh the data in API responses is. Use it to judge how far you can trust a value, or to reproduce an APY yourself. Summary: vaults.fyi reads contract state directly every hour (no protocol-reported numbers), stores it, and computes APY, TVL and scores from it; per-vault freshness is in `lastUpdateTimestamp` (Unix seconds), and the near-real-time (NRT) endpoints read chain state on demand.

## The indexing pipeline

Every hour, vaults.fyi runs purpose-built contracts as **static calls**. A static call executes without writing to chain storage, so it costs no gas and leaves no footprint.

- **Efficiency:** one call can read a value and feed it into the next calculation, which a standard multicall cannot do.
- **Consistency:** all values in one calculation are read at the same block height.

Results are stored in the vaults.fyi database and used for APY, TVL, scores and API responses. RPC requests are spread across Infura, Alchemy and Ankr so one provider's outage does not stall indexing.

## How share price is read, by vault type

APY is derived from share-price change (see [Calculating APY](/methodology/calculating-apy)). Each vault type exposes share price differently.

### ERC-4626 vaults: totalAssets / totalSupply

- `totalSupply()`: shares outstanding.
- `totalAssets()`: assets held by the vault.
- Share price = `totalAssets / totalSupply`.

### Non-ERC-4626 vaults: derived from mint, deposit, burn, redeem

Vaults that predate or do not implement ERC-4626 expose the share/asset relationship through function parameters or return values, typically `mint`, `deposit`, `burn` or `redeem`. Many need individual integration work.

### Liquid staking and restaking tokens (LSTs, LRTs)

- Total shares: `totalSupply()`.
- Total value: `getEthValue(totalSupply())`.

LSTs often post earnings in batches. When a batch lands, share price jumps and short-window APY (`1hour`, `1day`) spikes; `7day` and `30day` smooth it out.

### Rebasing supply tokens (for example Aave aTokens)

Rebasing tokens grow the holder's balance instead of the share price, so the ratio is inverted:

- `scaledTotalSupply()`: treated as total shares.
- `totalSupply()`: treated as total share value.

### Staking-mechanism vaults (StakeWise V2 style)

Some staking vaults do not auto-compound: principal and rewards are separate tokens, so the share/value ratio does not show yield. vaults.fyi simulates a share price:

```
total principal value = sETH2.totalSupply()
total rewards value   = rETH2.totalSupply()
TVL                   = total principal value + total rewards value
share price           = 1 + rETH2.rewardPerToken()
totalSupply           = TVL / share price
```

The resulting `totalSupply` is simulated, not read from a contract.

### Real-world-asset (RWA) vaults

RWA tokens represent offchain assets, so share price needs oracle prices:

- `totalSupply()`: total shares.
- `RWAOracle.price()`: RWA share price in USD.
- `StablecoinOracle.price()`: deposit-asset price in USD.

```
total shares in USD   = total shares × RWA oracle price
total shares in asset = total shares in USD / stablecoin oracle price
total shares value    = total shares in asset
```

## Data freshness

| What you need | Where to get it |
| - | - |
| When a vault's indexed data was last updated | `lastUpdateTimestamp` (Unix seconds) on `GET /v2/detailed-vaults` and `GET /v2/detailed-vaults/{network}/{vaultId}` |
| Indexed APY, TVL, score | Detailed-vault endpoints; updated once per hourly cycle |
| Current chain state between cycles | NRT endpoints: `GET /v2/nrt/vault/{network}/{vaultId}` and its single-value variants `/sharePrice`, `/totalAssets`, `/totalSupply`, `/underlyingAssetPrice` |

Indexed values reflect the last hourly cycle. A large deposit or earnings update in the past hour is not reflected until the next cycle completes. Example: `"lastUpdateTimestamp": 1792742400` = 2026-10-23 08:00 UTC.

NRT response units (real capture, `GET /v2/nrt/vault/base/0xbeeff2490FEffa212faC2f6553682C219E6a8845`, 2026-10-23):

```json
{
  "totalSupply": "461739224418397752974334633",
  "totalAssets": "468178256927439",
  "sharePrice": 1.013945135111877,
  "underlyingAssetPrice": 0.99985668
}
```

| Field | Unit |
| - | - |
| `totalSupply` | Integer string in **LP (share) token base units** (`lpToken.decimals`, here 18) |
| `totalAssets` | Integer string in **asset base units** (`asset.decimals`, here 6 for USDC) |
| `sharePrice` | Number: assets per whole share |
| `underlyingAssetPrice` | Number: USD price of the deposit asset |

NRT values are read from the chain's latest block when you call the endpoint (no response cache), so they are typically at most a block or a second old. Each NRT call costs 1 credit.

## Why direct indexing matters

Many aggregators take APY from protocol APIs or front ends, which often return model-based or forward-looking rates. vaults.fyi derives yield from raw contract state:

- **No dependence on protocol reporting.**
- **One method for every vault**, regardless of how the protocol presents its data.
- **Verifiable:** anyone with an archive node and the block heights used can reproduce the numbers.
