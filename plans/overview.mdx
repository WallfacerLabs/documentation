This page answers which vaults.fyi API plan fits your usage, what each costs, and what rate limit applies. It is the one place where plan rate limits are stated. Use it with [Credits](/plans/credits), which gives the credit cost of every endpoint.

Every API key can call every endpoint: v2, beta and alpha. Plans differ only in pricing model, included credits, rate limit and support. Usage is measured in credits (also called Compute Units); a simple lookup costs 1 credit, and list endpoints add a cost per returned item.

| Roadmap | — | Standard roadmap requests | Prioritized integrations for requested protocols | Prioritized integrations for requested protocols and chains; prioritized API features | Prioritized integrations and API features; custom feature development |

At pay-as-you-go prices, the Analyst allowance (250,000 credits) would cost $500, Growth (500,000) $1,000 and Builder (1,000,000) $2,000.

Who each plan is for:

- **Pay as you go:** testing, variable workloads, and agents. No commitment; switch to a subscription when usage becomes predictable.
- **Analyst:** researchers and data teams pulling data across protocols and chains.
- **Growth:** product teams launching yield features that need more included usage and throughput.
- **Builder:** applications at scale with high throughput needs.
- **Enterprise:** institutions and platforms needing custom volume, rate limits, SLAs or features. [Submit interest](https://vaultsfyi.fillout.com/t/tLA9t6HyAFus).

## Rate limits

Rate limits are set per API key as a number of requests per minute, enforced over a 60-second window, with bursts smoothed in 10-second buckets (about one sixth of the per-minute limit per 10 seconds). Requests without a key, including keyless x402 requests, are limited to 10 per minute per IP; that default is the "10 requests per minute" in the v2 spec. Limits per plan:

| Plan | Requests per minute | Average per second |
| - | - | - |
| Pay as you go | 600 | 10 |
| Analyst | 600 | 10 |
| Growth | 1,200 | 20 |
| Builder | 3,000 | 50 |
| Enterprise | Custom | Custom |
| No API key (including x402) | 10 per IP | — |

Limits can be raised for an individual key on request. The `x-ratelimit-limit` header shows the limit applied to your key: rely on it rather than on the plan name.

### Rate-limit headers

Authenticated responses, including most error responses, carry:

| Header | Meaning |
| - | - |
| `x-ratelimit-limit` | Requests allowed in the current window |
| `x-ratelimit-remaining` | Requests left in the current window |
| `x-ratelimit-reset` | Seconds until the window resets |

The headers are absent on 401 and 402 responses, on unknown-route 404s and on the public `/v2/health` endpoint.

When you exceed the limit the API returns HTTP 429 with a `Retry-After` header in seconds. Wait that long (or `x-ratelimit-reset` seconds) before retrying, and slow down before `x-ratelimit-remaining` reaches 0. Backoff code is on [Errors and rate limits](/api-reference/errors#retry-policy-and-backoff-code).

## When credits run out

When a key's credit balance reaches zero, priced endpoints return HTTP 403 `Forbidden` with "This API key has exhausted its available credits"; don't retry it, top up or upgrade instead. Free endpoints (`/v2/health`, alpha) keep working. See [Credits → When credits run out](/plans/credits#when-credits-run-out).

Pay-as-you-go keys have no spending cap: usage is billed per credit with no upper limit, so set your own budget alerts or call limits if you need one.

## Keyless access with x402

AI agents and other autonomous clients can call v2 REST endpoints without an API key by paying per request in USDC on Base with [x402](/ai-agents/x402). A v2 request sent without `x-api-key` returns HTTP 402 with the price. The price is the endpoint's credit cost × $0.002 (see [Credits → Credits and x402 prices](/plans/credits#credits-and-x402-prices)). x402 is available on `/v2/*` data endpoints and `POST /beta/advanced-analytics`; NRT, other beta and alpha endpoints and the MCP server need a key.

x402 payments don't draw on account credits. They are not exempt from rate limits: keyless traffic is limited to 10 requests per minute per IP.
