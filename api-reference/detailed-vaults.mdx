This section lists the v2 endpoints that return full vault analytics: APY windows, TVL, Reputation Score, fees, rewards, holders, warnings and flags. Use `/v2/detailed-vaults` to rank and filter many vaults, and the single-vault endpoints when you already know `network` and `vaultId`.

All requests go to `https://api.vaults.fyi` with the header `x-api-key: $VAULTSFYI_API_KEY`. Without a key, v2 endpoints return 402 (an [x402](/ai-agents/x402) payment challenge); beta, alpha and NRT endpoints need an API key. APY values are decimal fractions net of fees (`0.0315` = 3.15%); token amounts are integer strings in base units; timestamps are Unix seconds. See [Conventions](/api-reference/conventions).

## Endpoints

| Endpoint | Use it when | Required inputs | Credits |
| - | - | - | - |
| [`GET /v2/detailed-vaults`](/api-reference/detailed-vaults/list-detailed-vaults) | Rank and filter vaults with APY, TVL, Reputation Score, fees and warnings. Defaults: 4 networks, `minTvl=100000`, `sortOrder=asc`. | None | 1 + 3 per vault returned |
| [`GET /v2/detailed-vaults/{network}/{vaultId}`](/api-reference/detailed-vaults/get-vault-details) | Get the full detail object for one known vault. A vault that doesn't exist returns 400 "… not found". | Path: `network`, `vaultId` | 3 |
| [`GET /v2/detailed-vaults/{network}/{vaultId}/apy`](/api-reference/detailed-vaults/get-vault-apy) | Cheapest way to read one vault's current APY (`1day`, `7day`, `30day`, `90day`; no `1hour`). | Path: `network`, `vaultId` | 1 |
| [`GET /v2/detailed-vaults/{network}/{vaultId}/tvl`](/api-reference/detailed-vaults/get-vault-tvl) | Read one vault's current TVL (`usd` string, `native` base units). | Path: `network`, `vaultId` | 1 |

Credits are from [Credits](/plans/credits): base cost per call, plus a per-item cost where shown. Pay-as-you-go is $0.002 per credit. A `/v2/detailed-vaults` page with `perPage=50` costs up to 151 credits, so request only as many vaults as you need.

## Defaults that hide vaults

`GET /v2/detailed-vaults` applies these defaults when you omit the parameter:

| Parameter | Default | Effect |
| - | - | - |
| `allowedNetworks` | `base`, `mainnet`, `arbitrum`, `optimism` | Vaults on the other 18 networks are excluded. Repeat the key for each network you need. |
| `minTvl` | `100000` (USD, integer) | Vaults under $100k TVL are excluded. Pass `minTvl=0` to include them. |
| `sortOrder` | `asc` | With `sortBy=apy7day` the lowest APY comes first. Send `sortOrder=desc` to rank. |
| `allowVaultsWithWarnings` | `true` | Vaults with active warnings are included. Pass `false`, or inspect `warnings` and `flags`. |
| `allowCorrupted` | `false` | Vaults with corrupted data are excluded. |
| `perPage` | `50` (max 5000) | `nextPage` is omitted on the last page. |

Other rules:

- `sortBy` accepts `tvl`, `apy1day`, `apy7day`, `apy30day`, `apy90day`. `sortBy=apy` returns 400.
- Array filters (`allowedNetworks`, `allowedAssets`, `allowedProtocols`, `tags`, `curators`) must be repeated keys. `allowedNetworks=base,arbitrum` returns 0 results.
- `allowedAssets` takes ticker symbols (case-insensitive), not addresses.
- Unknown filter values return 200 with empty `data` and the value in `errors.unsupportedNetworks`, `unsupportedAssets` or `unsupportedProtocols`.
- `minVaultScore`: check `score.vaultScore` client-side if you need a strict threshold.

## APY in detailed-vault responses

- `apy` has five windows on list and detail responses: `1hour`, `1day`, `7day`, `30day`, `90day`. The `/apy` sub-resource has four (no `1hour`).
- Each window is `{base, reward, total}`, with `total = base + reward`, as a decimal fraction **net of fees**. The `fees` object is for display; don't subtract it again. See [How vaults.fyi calculates APY](/methodology/calculating-apy).
- Values are not clamped. Rows with 7-day APY above 1,500 (150,000%) exist. Treat APY above 1 (100%) as suspect.

## Example

```bash
curl -H "x-api-key: $VAULTSFYI_API_KEY" \
  "https://api.vaults.fyi/v2/detailed-vaults/base/0xbeeff2490FEffa212faC2f6553682C219E6a8845/apy"
```

Response, captured 2026-10-23 (complete):

```json
{
  "1day":  { "base": 0.0316, "reward": 0, "total": 0.0316 },
  "7day":  { "base": 0.0315, "reward": 0, "total": 0.0315 },
  "30day": { "base": 0.0305, "reward": 0, "total": 0.0305 },
  "90day": { "base": 0.0293, "reward": 0, "total": 0.0293 }
}
```

A full ranked-list example with its real response is on the [API overview](/api-reference/overview#your-first-request).
