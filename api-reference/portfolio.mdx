This section lists the v2 endpoints that read one wallet: its vault positions, idle (undeposited) tokens, suggested deposits, lifetime returns and event history. Use them for portfolio views and deposit recommendations. Nothing here moves funds; to build transactions, use [Transactions](/api-reference/transactions).

All requests go to `https://api.vaults.fyi` with the header `x-api-key: $VAULTSFYI_API_KEY`. Without a key, v2 endpoints return 402 (an [x402](/ai-agents/x402) payment challenge); beta, alpha and NRT endpoints need an API key. APY values are decimal fractions net of fees (`0.0315` = 3.15%); token amounts are integer strings in base units; timestamps are Unix seconds. See [Conventions](/api-reference/conventions).

## Endpoints

| Endpoint | Use it when | Required inputs | Credits |
| - | - | - | - |
| [`GET /v2/portfolio/positions/{userAddress}`](/api-reference/portfolio/list-portfolio-positions) | List a wallet's vault positions. Position size is `asset.positionValueInAsset` or `lpToken.balanceUsd`, not `asset.balanceUsd`. Defaults: 4 networks, `minTvl=100000`. | Path: `userAddress` | 5 |
| [`GET /v2/portfolio/positions/{userAddress}/{network}/{vaultId}`](/api-reference/portfolio/get-portfolio-position) | Get one wallet's position in one known vault (cheaper than listing). | Path: `userAddress`, `network`, `vaultId` | 1 |
| [`GET /v2/portfolio/idle-assets/{userAddress}`](/api-reference/portfolio/list-idle-assets) | List a wallet's tokens that are not deposited in a vault. Sort with `sortDirection` (not `sortOrder`). | Path: `userAddress` | 5 |
| [`GET /v2/portfolio/best-deposit-options/{userAddress}`](/api-reference/portfolio/get-best-deposit-options) | For each asset the wallet holds, get up to `maxVaultsPerAsset` (default 3) vaults ranked by APY. Defaults: `onlyAppFeatured=true`, `allowVaultsWithWarnings=false`. | Path: `userAddress` | 1 + 2 per vault returned |
| [`GET /v2/portfolio/best-vault/{userAddress}`](/api-reference/portfolio/get-best-vault) | Get the single best vault for the asset the wallet holds most of. Can return `isTransactional: false`; pass `onlyTransactional=true` before building a deposit. | Path: `userAddress` | 2 |
| [`GET /v2/portfolio/total-returns/{userAddress}/{network}/{vaultId}`](/api-reference/portfolio/get-total-returns) | Lifetime returns of a wallet in one vault (`returnsNative`, base units). | Path: `userAddress`, `network`, `vaultId` | 1 |
| [`GET /v2/portfolio/events/{userAddress}/{network}/{vaultId}`](/api-reference/portfolio/list-position-events) | All deposit and withdrawal events of a wallet in one vault. Not paginated; `items` is the total count. | Path: `userAddress`, `network`, `vaultId` | 3 |

Credits are from [Credits](/plans/credits): base cost per call, plus a per-item cost where shown. Pay-as-you-go is $0.002 per credit.

## Things to know

- **Default network scope.** `positions`, `idle-assets`, `best-vault` and `best-deposit-options` cover only base, mainnet, arbitrum and optimism unless you pass `allowedNetworks` (one repeated key per network). A wallet's positions on other networks are silently omitted.
- **Default `minTvl=100000`** on `positions`, `best-vault` and `best-deposit-options` hides positions in vaults under $100k TVL.
- **Position size is not `asset.balanceUsd`.** In positions, `asset.balanceNative` and `asset.balanceUsd` are the wallet's idle balance of the underlying token, repeated on every position in that asset. The position is `asset.positionValueInAsset` (base units) or `lpToken.balanceUsd`. Summing `asset.balanceUsd` over-counts. See [Conventions → Positions](/api-reference/conventions#positions-wallet-balance-vs-position-size).
- **Best-vault defaults differ** from list endpoints: `onlyAppFeatured=true` and `allowVaultsWithWarnings=false`. `best-vault` can still return a vault with `isTransactional: false`; pass `onlyTransactional=true` if you will build a deposit.
- **Idle assets** sort with `sortBy` + `sortDirection` (not `sortOrder`), with default `minUsdAssetValueThreshold=0.5`.
- **Not paginated.** These endpoints return `{data, errors}` with everything in one response. `events` returns `{asset, lpToken, data, items}`, where `items` is the total count.
- `userAddress` must be `0x` + 40 hex characters. ENS names return 400. Addresses are case-insensitive.
- Path order is user, then network, then vault: `/v2/portfolio/positions/{userAddress}/{network}/{vaultId}`.

## Example

```bash
# Default scope: base, mainnet, arbitrum, optimism. Add allowedNetworks=<name> (repeated) for others.
curl -H "x-api-key: $VAULTSFYI_API_KEY" \
  "https://api.vaults.fyi/v2/portfolio/positions/0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045"
```

Response, captured 2026-10-23 (trimmed to 1 of 10 positions and key fields):

```json
{
  "data": [
    {
      "vaultId": "0xae7ab96520DE3A18E5e111B5EaAb095312D7fE84",
      "name": "Lido stETH",
      "network": { "name": "mainnet", "chainId": 1, "networkCaip": "eip155:1" },
      "asset": {
        "symbol": "ETH",
        "decimals": 18,
        "balanceNative": "5773252986299759339",
        "balanceUsd": "13850.55495425",
        "positionValueInAsset": "10424842274072"
      },
      "lpToken": { "symbol": "stETH", "decimals": 18, "balanceNative": "10424842274072", "balanceUsd": "0.0250101374648113525898504" }
    }
  ],
  "errors": { "unsupportedNetworks": [], "unsupportedAssets": [], "unsupportedProtocols": [] }
}
```

Here the wallet holds 5.77 idle ETH (`asset.balanceUsd` ≈ $13,850), but the Lido position is worth about $0.025 (`lpToken.balanceUsd`).
