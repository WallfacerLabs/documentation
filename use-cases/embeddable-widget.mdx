The vaults.fyi widget gives wallets, exchanges, and consumer apps a configurable interface for surfacing yield opportunities, supporting user actions, and showing positions.

</Note>

## Widget vs. API or SDK

Use the widget when you want a branded Earn experience without designing every vault list, deposit form, position view, and transaction state yourself. Use the API or SDK when you want full control over the interface and business logic.

| Integration path | Best for |
|------------------|----------|
| Embeddable widget | Branded Earn surfaces, partner launches, curated vault lists, portfolio views, and transaction-ready flows with less product and frontend work |
| API or SDK | Fully custom discovery, routing, portfolio, transaction, attribution, or analytics experiences built inside your own application |

## Support discovery, positions, and transactions

The widget can present a compact Discover experience, a user’s existing positions, or both.

For transaction-enabled integrations, it supports host-controlled signing and custody handoff flows. Your product keeps control of the wallet experience while vaults.fyi provides the underlying opportunity data and transaction context.

## How integration works

<Steps>
  <Step title="Configure the opportunity set">
    Choose the networks, assets, protocols, vaults, curators, tags, TVL thresholds, reputation score threshold, APY window, sort order, and views available in the widget.
  </Step>
  <Step title="Apply your brand settings">
    Set the theme, accent color, font, corner radius, widget title, attribution preference, and visible data fields.
  </Step>
  <Step title="Embed the widget">
    Add the generated embed code or React component to your app. Your team controls where the widget appears and which mode is shown.
  </Step>
  <Step title="Connect wallet context">
    Let the widget use the connected wallet context or pass the relevant wallet state from your host app, including EVM and Solana accounts where supported.
  </Step>
  <Step title="Handle transactions">
    For live transaction flows, vaults.fyi provides the opportunity data and transaction context while your product controls signing, broadcasting, and custody handoff.
  </Step>
</Steps>

## Non-custodial by design

Vaults.fyi does not custody user funds. Transaction-enabled widget flows use vaults.fyi infrastructure for data and transaction preparation, while your app keeps control of the wallet experience. Users sign with their own wallet, and funds route to the target protocol contracts.

## Built on vaults.fyi coverage

The widget uses vaults.fyi’s normalized vault data and transaction infrastructure across supported EVM networks and Solana/SVM coverage. Teams can keep their interface focused while extending coverage as their product grows.
