This page explains what the vaults.fyi API does and how to make your first request: base URL, authentication, the defaults that change results, and where to go next. Read it first if you are new to vaults.fyi or are an AI agent deciding which page to load. The API serves normalized yield data for DeFi vaults, builds unsigned transactions for those vaults, and reports wallet positions. Request: `https://api.vaults.fyi` plus a versioned path (`/v2/...`), with your key in the `x-api-key` header.

## What vaults.fyi covers

| Area | What you get | Main endpoints |
| - | - | - |
| Yield and market data | APY (decimal fraction, net of fees), TVL, fees, rewards, Reputation Score, flags, holders, capacity | `GET /v2/detailed-vaults`, `GET /v2/detailed-vaults/{network}/{vaultId}` |
| History and benchmarks | APY, TVL and share-price time series; USD and ETH benchmark rates | `GET /v2/historical/{network}/{vaultId}`, `GET /v2/benchmarks/{network}` |
| Transactions | Unsigned, ready-to-sign deposit, redeem, queued-withdrawal and reward-claim calls sent straight to the protocol contract | `GET /v2/transactions/context/{userAddress}/{network}/{vaultId}`, `GET /v2/transactions/{action}/{userAddress}/{network}/{vaultId}` |
| Portfolio | A wallet's vault positions, idle tokens, returns, events and deposit suggestions | `GET /v2/portfolio/positions/{userAddress}`, `GET /v2/portfolio/idle-assets/{userAddress}` |
| Beta surfaces | Borrow markets, Solana (SVM) vaults, advanced analytics, fixed-term markets | `/beta/...` (may change before general availability) |

Coverage: 3,000+ vaults (taken from `GET /v2/vaults`), 80+ protocols (126 protocol IDs from `GET /v2/protocols` on 2026-10-23), 22 EVM networks (`GET /v2/networks`), plus Solana vaults on the Beta SVM endpoints. Use the reference endpoints for current numbers rather than these counts. See [Supported protocols and networks](/concepts/supported-protocols).

## Authentication and base URL

- **Base URL:** `https://api.vaults.fyi`. Every path already starts with its version (`/v2`, `/beta`, `/alpha`). Do not add `/v2` to the base URL: `https://api.vaults.fyi/v2` + `/v2/detailed-vaults` doubles the version prefix and fails.
- **REST auth:** send `x-api-key: <your key>` on every request. Get a key at [portal.vaults.fyi/signup](https://portal.vaults.fyi/signup).
- **MCP auth is different:** the hosted MCP server uses `Authorization: Bearer <key>`. The REST API does not accept `Authorization: Bearer`; a REST call with only that header is treated as keyless.
- **No key → HTTP 402**, not 401. The 402 body is an x402 payment challenge (pay per request in USDC on Base). An invalid key → HTTP 401. See [Errors](/api-reference/errors) and [x402](/ai-agents/x402).
- `GET /v2/health` is public and needs no key.

## Your first request

This call lists the three highest 7-day-APY USDC vaults on Base. Replace nothing; it reads the key from the environment.

```bash
curl -s "https://api.vaults.fyi/v2/detailed-vaults?allowedNetworks=base&allowedAssets=USDC&sortBy=apy7day&sortOrder=desc&perPage=3" \
  -H "x-api-key: $VAULTSFYI_API_KEY"
```

```python
import os, requests

r = requests.get(
    "https://api.vaults.fyi/v2/detailed-vaults",
    headers={"x-api-key": os.environ["VAULTSFYI_API_KEY"]},
    params={"allowedNetworks": "base", "allowedAssets": "USDC",
            "sortBy": "apy7day", "sortOrder": "desc", "perPage": 3},
)
r.raise_for_status()
for v in r.json()["data"]:
    print(v["name"], v["apy"]["7day"]["total"], v["score"]["vaultScore"])
```

```typescript
const url = new URL("https://api.vaults.fyi/v2/detailed-vaults");
url.search = new URLSearchParams({
  allowedNetworks: "base", allowedAssets: "USDC",
  sortBy: "apy7day", sortOrder: "desc", perPage: "3",
}).toString();
const res = await fetch(url, { headers: { "x-api-key": process.env.VAULTSFYI_API_KEY! } });
if (!res.ok) throw new Error(`HTTP ${res.status}: ${await res.text()}`);
const body = await res.json();
for (const v of body.data) console.log(v.name, v.apy["7day"].total, v.score.vaultScore);
```

## Defaults that silently change results

| Behavior | Detail |
| - | - |
| Default network scope | `GET /v2/detailed-vaults` and the `/v2/portfolio/*` list endpoints return only `base`, `mainnet`, `arbitrum` and `optimism` unless you pass `allowedNetworks`. `GET /v2/vaults` and `GET /v2/assets` have no default scope. |
| Default TVL floor | `minTvl` defaults to `100000` (USD) on detailed-vaults and portfolio endpoints. Pass `minTvl=0` to include small vaults. |
| Default sort | `sortOrder` defaults to `asc`, so sorting by APY without `sortOrder=desc` returns the lowest first. |
| Array parameters | Repeat the key: `allowedNetworks=base&allowedNetworks=arbitrum`. A comma list returns 200 with 0 results and the value echoed in `errors.unsupportedNetworks`. |
| Last page | `nextPage` is absent (not `null`) on the last page. There is no total count. |
| Units | APY is a decimal fraction (`0.0316` = 3.16%). Token amounts are integer strings in base units (1 USDC = `"1000000"`). Timestamps are Unix seconds. |

Full rules: [API conventions](/api-reference/conventions).
