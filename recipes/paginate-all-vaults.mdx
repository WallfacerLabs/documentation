This recipe answers "how do I get **all** vaults, not just the first page?" It pages through `/v2/vaults` (identity list, every network) and `/v2/detailed-vaults` (full metrics) until the last page, overrides the defaults that silently hide vaults, and estimates the credit cost. Use it for bulk exports, nightly syncs and analytics backfills.

Every request goes to `https://api.vaults.fyi` with the header `x-api-key: $VAULTSFYI_API_KEY`. All code on this page was run on 2026-10-23; outputs are real and trimmed.

## Benchmark tasks covered

T02 (paginate every vault). See the [recipes overview](/recipes/overview).

## Prerequisites

- An API key exported as `VAULTSFYI_API_KEY`.
- curl and jq, Python 3.9+ with `requests`, or Node.js 18+.

**Scope of the recorded examples:** the queries below omit `allowCorrupted`, so they exclude corrupted vaults (`allowCorrupted=false` by default). They are not an unfiltered inventory. To enumerate every vault, pass `allowCorrupted=true` on both `/v2/vaults` and `/v2/detailed-vaults`. For full detailed coverage also pass all desired networks, `minTvl=0`, remove the example's `allowedAssets=USDT0` restriction, and set `allowVaultsWithWarnings=true` explicitly (already the detailed-list default). The identity list has no warnings filter. Including corrupted/warned records is for completeness, not a recommendation to deposit.

## How pagination works

| Rule | Value |
| - | - |
| Envelope | `{ itemsOnPage, nextPage?, data: [...], errors? }` |
| First page | `page=0` (zero-based) |
| Last page | `nextPage` is **absent** (the key is missing, it is never `null`) |
| Page size | `perPage` default 50, max 5000 (historical endpoints: 20000); `0` is a 400 |
| Total count | Not returned. Count rows yourself. |
| Unpaginated | `/v2/portfolio/*` returns `{ data, errors }` with no `nextPage` |

## Credit cost

| Endpoint | Cost | This run |
| - | - | - |
| `GET /v2/vaults` | 1 per call, any `perPage` | 3,662 vaults in 1 call (`perPage=5000`) = **1 credit** |
| `GET /v2/detailed-vaults` | 1 per call + 3 per vault returned | 72 USDT0 vaults in 8 pages = 8 + 216 = **224 credits** |

A full-market `/v2/detailed-vaults` pull costs about 3 credits per vault, so 3,662 vaults ≈ 11,000 credits. Pull identities from `/v2/vaults` and fetch detail only for the vaults you need ([credits](/plans/credits)).

## Step 1: the loop (curl)

This loop pages USDT0 vaults on Plasma and Ethereum with `perPage=10` to show several pages; use a larger `perPage` in production.

```bash
# Page through /v2/detailed-vaults until nextPage is absent (it is never null).
page=0
while :; do
  body=$(curl -sS --fail-with-body -G "https://api.vaults.fyi/v2/detailed-vaults" \
    -H "x-api-key: $VAULTSFYI_API_KEY" \
    --data-urlencode "allowedNetworks=plasma" --data-urlencode "allowedNetworks=mainnet" \
    --data-urlencode "allowedAssets=USDT0" --data-urlencode "minTvl=0" \
    --data-urlencode "perPage=10" --data-urlencode "page=$page") || { echo "$body"; exit 1; }
  echo "$body" | jq -r '.data[] | "\(.network.name)\t\(.tvl.usd)\t\(.name)"'
  next=$(echo "$body" | jq -r 'if has("nextPage") then .nextPage else "none" end')
  [ "$next" = "none" ] && break
  page=$next
done
```

## Step 2: a reusable fetch-all (Python)

```python
"""Fetch every page of a vaults.fyi list endpoint safely (stop when nextPage is absent)."""
import os
import time

import requests

API = "https://api.vaults.fyi"
session = requests.Session()
session.headers["x-api-key"] = os.environ["VAULTSFYI_API_KEY"]


def fetch_all(path, params, per_page=1000, max_pages=1000):
    """Return (rows, calls). params is a list of (key, value) tuples so array
    params can repeat. page is zero-based; nextPage is OMITTED on the last page."""
    rows, page, calls = [], 0, 0
    while calls < max_pages:  # hard cap: never loop forever
        r = session.get(f"{API}{path}", params=params + [("page", page), ("perPage", per_page)], timeout=60)
        r.raise_for_status()
        body = r.json()
        calls += 1
        bad = {k: v for k, v in (body.get("errors") or {}).items() if v}
        if bad:
            raise ValueError(f"filter values rejected: {bad}")
        rows.extend(body["data"])
        if "nextPage" not in body:  # last page: key absent (never null)
            break
        page = body["nextPage"]
        time.sleep(0.2)  # stay well under your plan's rate limit
    return rows, calls


# 1) Identity list of every NON-CORRUPTED vault on every network: /v2/vaults has no default
#    network filter and costs a flat 1 credit per call.
vaults, calls = fetch_all("/v2/vaults", [], per_page=5000)
networks = sorted({v["network"]["name"] for v in vaults})
print(f"/v2/vaults: {len(vaults)} vaults on {len(networks)} networks in {calls} call(s)")

# 2) Detailed data across ALL networks. /v2/detailed-vaults defaults to
#    base, mainnet, arbitrum, optimism and minTvl=100000 -- override both.
#    These recorded queries exclude corrupted vaults; see the full-inventory flags above.
#    Take network names from the vault list: /v2/networks also lists networks
#    with no vaults, which detailed-vaults reports in errors.unsupportedNetworks.
params = [("allowedNetworks", n) for n in networks] + [("allowedAssets", "USDT0"), ("minTvl", 0)]
detailed, calls = fetch_all("/v2/detailed-vaults", params, per_page=10)
credits = calls * 1 + 3 * len(detailed)  # 1 credit per call + 3 per vault returned
print(f"/v2/detailed-vaults USDT0: {len(detailed)} vaults in {calls} pages, ~{credits} credits")
for v in sorted(detailed, key=lambda v: -int(v["tvl"]["usd"]))[:3]:
    print(f'  {v["network"]["name"]:8} {v["name"][:36]:36} TVL ${int(v["tvl"]["usd"]):,}')
```

## Step 2: a reusable fetch-all (TypeScript)

```typescript
// Fetch every page of a vaults.fyi list endpoint safely (stop when nextPage is absent).
const API = 'https://api.vaults.fyi';
const headers = { 'x-api-key': process.env.VAULTSFYI_API_KEY! };

type Page<T> = { itemsOnPage: number; nextPage?: number; data: T[]; errors?: Record<string, string[]> };

async function fetchAll<T>(path: string, params: [string, string][], perPage = 1000, maxPages = 1000) {
  const rows: T[] = [];
  let page = 0;
  let calls = 0;
  while (calls < maxPages) { // hard cap: never loop forever
    const qs = new URLSearchParams([...params, ['page', String(page)], ['perPage', String(perPage)]]);
    const res = await fetch(`${API}${path}?${qs}`, { headers });
    if (!res.ok) throw new Error(`HTTP ${res.status}: ${await res.text()}`);
    const body = (await res.json()) as Page<T>;
    calls += 1;
    const bad = Object.entries(body.errors ?? {}).filter(([, v]) => v.length);
    if (bad.length) throw new Error(`filter values rejected: ${JSON.stringify(bad)}`);
    rows.push(...body.data);
    if (body.nextPage === undefined) break; // last page: key absent (never null)
    page = body.nextPage;
    await new Promise((r) => setTimeout(r, 200)); // stay under your rate limit
  }
  return { rows, calls };
}

// 1) Identity list of every NON-CORRUPTED vault: /v2/vaults has no default network filter (1 credit/call).
const all = await fetchAll<{ network: { name: string } }>('/v2/vaults', [], 5000);
const nets = new Set(all.rows.map((v) => v.network.name));
console.log(`/v2/vaults: ${all.rows.length} vaults on ${nets.size} networks in ${all.calls} call(s)`);

// 2) Detailed data across ALL networks: override the 4-network default and minTvl=100000.
//    These recorded queries exclude corrupted vaults; see the full-inventory flags above.
//    Take network names from the vault list: /v2/networks also lists networks with
//    no vaults, which detailed-vaults reports in errors.unsupportedNetworks.
const params: [string, string][] = [
  ...[...nets].map((n): [string, string] => ['allowedNetworks', n]),
  ['allowedAssets', 'USDT0'],
  ['minTvl', '0'],
];
type V = { name: string; network: { name: string }; tvl: { usd: string } };
const detailed = await fetchAll<V>('/v2/detailed-vaults', params, 10);
const credits = detailed.calls + 3 * detailed.rows.length; // 1/call + 3/vault
console.log(`/v2/detailed-vaults USDT0: ${detailed.rows.length} vaults in ${detailed.calls} pages, ~${credits} credits`);
for (const v of [...detailed.rows].sort((a, b) => Number(b.tvl.usd) - Number(a.tvl.usd)).slice(0, 3)) {
  console.log(`  ${v.network.name.padEnd(8)} ${v.name.slice(0, 36).padEnd(36)} TVL $${Number(v.tvl.usd).toLocaleString('en-US')}`);
}
```

## Pitfalls

- **Checking `nextPage === null` or `nextPage == None`.** It is never null: the key is missing on the last page. Test for presence (`"nextPage" not in body`, `body.nextPage === undefined`).
- **Treating the response as an array.** Rows are in `data`; `itemsOnPage` is the count on this page, not the total.
- **Default scope on `/v2/detailed-vaults`.** Only base, mainnet, arbitrum and optimism, and only vaults with TVL ≥ $100,000. Pass every network (repeated `allowedNetworks` keys), `minTvl=0`, `allowCorrupted=true` and `allowVaultsWithWarnings=true`, with no asset restriction, for a full detailed pull. `/v2/vaults` has no network default but also needs `allowCorrupted=true` for a complete identity list.
- **Taking network names from `/v2/networks`.** It lists networks with no vaults, which `/v2/detailed-vaults` reports in `errors.unsupportedNetworks`; the snippets treat that as an error. Use the names seen in `/v2/vaults`.
- **Unbounded loops.** Cap the number of pages and sleep between calls; watch `x-ratelimit-remaining` ([errors](/api-reference/errors#429-rate-limit-exceeded)).
- **Large `perPage` on detailed endpoints.** Cost scales with rows returned, not calls.
